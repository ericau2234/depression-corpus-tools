# 三层数据浏览器 · 模板

一个手机优先嘅三层数据浏览页：第一层大分类 → 第二层细项 → 第三层具体项。
成个模板就系一个 `index.html`，**单一自包含文件**：冇构建步骤、冇外部依赖（唔使联网、唔使装任何嘢），浏览器直接打开就用得。

入面嘅示例数据系虚构嘅「鲜果店顾客评价」分类，用嚟示范格式；换成你自己嘅三层分类数据就系一个成品页。

## 五个视图

- **列表**（预设）：大分类逐行排好，每行有篇数、占比同一句介绍；撳掣展开细项，再展开具体项。每个细项有个状态标：第三层已完成／已试拆 · 保留第二层／第三层未细分。
- **具体原因**：所有有第三层嘅支一次过排晒，逐支列明每个具体项嘅数字同原句；页面底部有固定大掣一撳直达。页尾有两张自动生成嘅清单：未细分嘅细项（逐大类列）同试拆后保留第二层嘅细项（连原因），唔使自己维护。
- **按年份**：拣数据层（两个层）再拣年份，睇嗰年各大类嘅每百篇比例（连全期平均对照），下面有走势图，拣一个分类或者特别系列睇佢逐年升跌。样本薄嘅年份有黄标提醒；冇数据嘅年份条线会断开，唔会驳埋。
- **按来源**：同一套分类套落每个来源分开计。来源掣写明已分类数同语料总数；逐来源卡列每百篇比例（由篇数即时计出，连特别系列三口径）兼标头三位；下面有跨来源对照表，每行最劲嗰格标红，另有一列「合并（全部来源）」系将各来源篇数加总再计出嚟嘅。
- **圈图**：同心圈图。全图只画最外圈大分类，撳入一支先画佢嘅内圈；旁边有明细面板，撳边行去边层。

另外有：页首**细分进度块**（几多支细项已拆到第三层、几多支保留第二层、几多支未细分，全部由数据计出，附进度条同直达掣）、顶部**重点横幅**（自选几个大类合计 + 一排节点捷径掣，数字全部由数据即时计出）、**搜寻**（打字即出结果，撳结果直达嗰项）、热门搜寻示例掣。

## 数据格式

数据全部喺 `index.html` 尾部嘅 `<script>` 入面，分三橛俾注释框住：
`/* ===== DATA: replace this block ===== */`、`/* ===== YEAR DATA: replace this block ===== */` 同 `/* ===== PLATFORM DATA: replace this block ===== */`，加年份视图附近嘅 `YCATS` 一行。字段名以下为准（同代码入面一模一样）。

### 1. DATA（三层树）

```js
var DATA = { name:"全部", children:[ /* 第一层大类 */ ] };
```

- 第一层（大类）：`{ name, count, color, star?, children }`
  - `count`：呢个大类嘅记录篇数。页面占比按全部大类 `count` 加总（分类命中次数）计，一篇记录可以入几个大类，所以占比唔使加到 100%。
  - `color`：十六进制色，如 `"#c0392b"`；第二、三层嘅色会自动由佢推浅，唔使逐个写。
  - `star: true`（可选）：表示呢类用较松口径计，名后面会加 ＊，并提示「数字当上限睇」。
- 第二层（细项）：`{ name, rate, pool?, children?, keep2?, note? }`
  - `rate`：每一百篇该大类记录入面，有几多篇提到呢个细项。篇数由 `count × rate / 100` 推算。
  - `pool`：嗰一支嘅记录实数。**有第三层嗰啲细项要写**，第三层篇数用 `pool × rate / 100` 计；冇写就用推算值顶住。
  - `keep2: true`（可选）：呢支试拆过第三层、决定保留喺第二层；配埋 `note:"一句原因"`，列表会标「已试拆 · 保留第二层」，具体原因页尾嘅保留清单会列埋原因。冇 `children` 又冇 `keep2` 嘅支，会自动入页尾「未细分」清单（计数同进度块都系自动计，唔使自己数）。
- 第三层（具体项）：`{ name, rate }`，`rate` = 每一百篇嗰支（pool）记录入面有几多篇。

唔使自己写「其他」行：如果某一层啲细项加埋唔够嗰层总数嘅 98.5%，页面会自动补一行「其他／未细分」（第二层）或者「池内其他／未明文」（第三层），篇数系剩余数。

### 2. QUOTES（原句）

```js
var QUOTES = { "第三层项名": "一句原话（节录）", ... };
```

键系第三层（或者第二层）项嘅 `name`，一模一样先对得上；冇原句嘅项唔使写。

### 3. INTRO（大类介绍）

```js
var INTRO = { "大类名": "一句白话介绍", ... };
```

每个大类一句，显示喺列表同圈图面板度。

### 4. META（总数同设定）

```js
var META = { docTotal:11842, docLabel:"已分类评价", thinN:1000 };
```

- `docTotal`：已分类记录总数（篇），同下面 `YEAR_DATA.posts.totN` 应该一致。
- `docLabel`：呢个总数嘅叫法，显示喺统计列同圈图中心。
- `thinN`：年份视图入面，某年已分类篇数低于呢个值就标「样本较薄」。

### 5. HIGHLIGHT（顶部重点横幅）

```js
var HIGHLIGHT = { title:"…", totalLabel:"…", cats:["大类名", …], items:["节点名", …], note:"…" };
```

- `cats`：要合计嘅大类名，横幅总数同占比由页面即时计出。
- `items`：横幅入面一排捷径掣，每个系任何一层嘅节点名，撳咗直达。入面可以放一个唔属于 `cats` 嘅相关项（示例就系咁做），喺 `note` 写明佢冇计入总数就得。

### 6. HL + YEAR_DATA（按年份）

```js
var HL = { cardTitle:"…", series:["价格·严","价格·宽","价格·痕迹"], colors:["#b4472a","#c07f16","#8a6d1f"], note:"…" };
```

`HL` 系年份视图入面一个特别系列嘅三口径（名、色、说明）；`series` 嘅顺序要同 `YEAR_DATA` 每年嘅 `hl` / `hlC` 数组下标一一对应，唔用可以成组删走（连 YEAR_DATA 嘅 `hl`、`hlC`、`totHl` 一齐删，并喺代码 `yVal`、`renderYearCard`、`buildTrendChips` 入面删走引用 `HL` 嗰几行）。

```js
var YEAR_DATA = {
  "posts":    { totN, tot:{ 大类名: 全期每百篇 }, totHl:[严,宽,痕迹], years:{ "2022":{…}, … }, note:"…" },
  "comments": { 同上结构 }
};
```

- 两个层嘅键固定系 `posts` 同 `comments`；佢哋嘅显示名喺 DATA 橛入面嘅 `YEAR_LAYERS` 改（例：`{ posts:"评价", comments:"追评" }`）。只有一个层就删走另一个键同对应掣（`ylComments`）。
- 每年：`{ n, long, p, c, hl, hlC }`
  - `n`：嗰年已分类篇数；`long`：嗰年记录总数（未分类都计）。
  - `p`：`{ 大类名: 每一百篇已分类有几多篇 }`；`c`：`{ 大类名: 篇数 }`，应该约等於 `p × n / 100`。
  - `hl` / `hlC`：特别系列三口径嘅每百篇数同篇数（对应关系同 `p` / `c` 一样）。
  - `totN` = 各年 `n` 加总；`tot` 同 `totHl` 系全期数（按篇数加权平均，唔好随手填）。
  - `note`（可选）：嗰一层显示喺年份卡下面嘅备注。
- `YCATS`：年份视图用嘅大类名数组，顺序即显示顺序；入面嘅名要同 `YEAR_DATA` 嘅 `p` / `c` / `tot` 键完全一致，亦要系 DATA 第一层嘅名（走势图攞色靠佢对返大类）。
- `INCOMPLETE_YEAR`：未过完嗰年嘅年份字串（如 `"2025"`），页面会标「未完」；冇就填一个唔存在嘅值。
- `YEAR_DEFAULT`：预设显示嘅年份，要系 `years` 入面有嘅键。

### 7. PLATFORMS（按来源）

喺 `/* ===== PLATFORM DATA: replace this block ===== */` 橛（喺 YEAR DATA 橛之后）：

```js
var PLATFORMS = [
  { id:"web", name:"网店", tag:"自营网店", draft:false, n:5200, total:9100, long:7600,
    c:{ "苹果类":1420, "柑橘类":1260, … }, hlC:[780,1140,2260], note:"一句来源说明" },
  …
];
```

- `id`：内部标识，唔重复就得；`name`：来源名（显示用）；`tag`（可选）：来源掣同卡上面嘅小字。
- `n`：嗰个来源嘅已分类记录数；`total`：语料总数；`long`：长记录数。已分类率由页面用 `n ÷ long` 即时计，唔使填。
- `c`：每个大类嘅篇数，键要同 `YCATS`／DATA 第一层名一模一样。**百分比唔使填**：每百篇比例全部由 `c ÷ n` 即时计出（来源卡同对照表都系）。
- `hlC`：特别系列（`HL.series`）三口径嘅篇数，顺序同 `HL.series` 对应；比例同样由 `hlC ÷ n` 计。如果成个 `HL` 删走咗，呢个字段同平台代码入面引用 `HL` 嗰几行要一齐删。
- `draft: true`（可选）：呢个来源数据未齐，页面会标「初稿」。`note`（可选）：来源卡底部嘅一句说明；写入面嘅数字系写死嘅文案，改数据时记得对返。
- **合并列唔使写数据**：页面会将各来源嘅 `n`、`total`、`long`、`c`、`hlC` 加总，再计百分比（唔系将各来源百分比求平均），标做「合并（全部来源）」，而且唔会俾佢赢「每行最劲」嗰格嘅标红。要全页对得返数，就令各来源 `c` 加总对返你主样本嘅大类命中数、`n` 加总对返 `META.docTotal`（示例就系咁对齐：n 合计 11,842，合并比例同 YEAR DATA 全期 `tot` 一致）。
- 冇来源拆分数据就成橛删走 `PLATFORMS`，同时删走按来源视图嘅 HTML（`platView` 一节）、掣（`viewPlatBtn`）同 JS（`setView` 入面 `plat` 嗰几行 + 「按来源视图」成段代码）。

## 点换自己嘅数据

1. 改 DATA 橛（`DATA`、`QUOTES`、`INTRO`、`META`、`HIGHLIGHT`、`HL`、`YEAR_LAYERS`、`INCOMPLETE_YEAR`、`YEAR_DEFAULT`）。
2. 改 YEAR DATA 橛（`var YEAR_DATA=…` 一整行）同佢下面嘅 `YCATS`。
3. 改 PLATFORM DATA 橛（`var PLATFORMS=…`）：每个来源填 `n`、`total`、`long`、`c`、`hlC` 就得，百分比唔使填。
4. 改页面嘅静态文案：页首标题同副题、页脚嘅口径说明、搜寻框 placeholder、热门搜寻掣——**掣上面嘅 `data-chip` 属性要等於数据入面某个节点嘅名**，撳落去先跳得中。
5. 打开页面核对：统计列嘅数字、横幅总数、每个大类嘅占比、进度块、对照表嘅合并列都系由数据即时计出嚟嘅，数据啱就自动啱。

## 点用

- 本机睇：直接双击 `index.html`（或者拖入浏览器）就得，唔使起 server。
- 放上网：用 GitHub Pages——仓库 Settings → Pages → Source 拣 `Deploy from a branch`，选好分支之后，呢个文件夹嘅路径就系现成页面（或者将 `index.html` 放到仓库根目录/ docs 文件夹再开 Pages）。
- 改样式：颜色、字体、深浅色都喺页首 `<style>` 嘅 CSS 变量度（`:root` 同 `prefers-color-scheme: dark` 两组），改嗰度就全页跟住变。
