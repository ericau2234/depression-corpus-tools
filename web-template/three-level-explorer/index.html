按年份睇：边年多人提到边样？

逐年用同一套分类重计。数字 = 嗰年每一百篇已分类记录入面，有几多篇提到呢个分类（一篇可入多类）。每个年份掣下面写明嗰年有几多篇已分类记录——边年样本薄，边年个比例就越易大上大落，唔好当真数咁咬实。

睇边层：

走势：拣一个分类，睇佢逐年升跌

纵轴 = 每 100 篇已分类记录有几多篇（由 0 起）。横轴按真年份距离排，冇数据嗰年会断线，唔会驳埋扮连续。

按来源睇：唔同来源唔同性格

同一套分类、同一口径，套落每个来源分开再计。数字 = 嗰个来源每一百篇已分类记录入面，有几多篇提到呢个分类（一篇可入多类）。每个来源掣下面同时写明语料总数同已分类数，两个数唔好撈乱；百分比全部由篇数即时计出，唔系另外填嘅。

跨来源对照：一眼睇晒边个来源边样最劲

每格 = 每 100 篇已分类记录有几多篇；每行最劲嗰格标红（「合并」列唔计）。合并列系各来源篇数加总之后再计过，唔系将百分比求平均。

点睇：来源性格可以差好远，先睇每个来源自己排头三位嗰几样，再同合并列对。样本细嘅来源比例波幅会大啲，唔好同大样本来源斤斤计较零点几。

全图只画最外圈大分类。撳任何一格入嗰支，先会画埋佢嘅细项同具体项；未细分嘅部分唔画灰格，篇数喺右边清单列明。

点读数：第一层数字系该大类嘅记录数（一篇可以同时入几个大类，所以占比按 12,020 次分类命中计，唔好当百分比加总）。第二层数字系「每一百篇该大类记录入面有几篇提到呢个细项」；第三层系「每一百篇嗰一支记录入面有几篇」。清单入面「其他／未细分」嗰行系冇明文提到更细项嘅部分，唔系漏计。
