# 抑郁成因研究 · 方法文档

_记录这项研究实际用了什么工具、什么方法、各平台的资料是怎样搜出来和抓回来的。写于 2026-11-03，对应工作：科学综述报告（为什么人会忧郁）+ 语料采集验收报告（v1–v2.2）。_

## 一、整个报告的模式：双轨

整个研究分上下两轨，互相印证：

- **上轨 · 科学综述**：回答「学界认为人为什么会忧郁」。方法是对学术文献做博士级综述（遗传学、神经科学、心理学、社会流行病学），结论是生物—心理—社会模型 + 素质—应激框架，没有单一病因。
- **下轨 · 语料实证**：回答「患者和社群自己说为什么」。方法是全网抓取患者/社群的第一人称叙述，清洗成统一语料，再用词典分类统计归因分布，与上轨对照（最典型的对照：患者自述提到遗传的只有约 0.4–0.8%，而双生子研究遗传度是 37%——文本量的是「提到」，不是「根源」，这一区分贯穿全研究）。

验收报告的结构固定为四块：**采到什么（平台逐个交代入口、数量、质量）→ 怎样清洗 → 怎样分类计数（口径先行）→ 争议问题的裁决（经济学辩论三层结论）**。每一版（v1、v2、v2.1、v2.2）都往同一份验收报告后面追加章节，不另起炉灶；每个主题一份独立报告是既定体例。

## 三、各平台的搜集方法（入口 + 关键坑）

- **Reddit**：主战场。官方 .json 返回 403，改走 Arctic-Shift：先按 subreddit 列表分页抓帖，再升级为「窗口分片深度拖网」——25 个版块 × 2017–2026 十年 ×（帖子+评论）切成 500 个窗口任务，10 个 worker 并行，逐窗口落盘 + 完成标记，断了可续。续跑曾有个真 bug：重启后每个窗口从最新一页重走、旧数据全重复不落盘，计数冻结——修法是读已有文件里最旧一条的时间戳，从那里接续。另设广度波：50 个情绪全域版块（原生家庭、断亲、丧亲、照顾者、成瘾、贫困、债务、学生贷款等）全扫，专门服务「溯源是否金钱问题」。
- **Bilibili**：游客搜索必须先经 finger/spi 接口取 buvid3/buvid4 cookie，裸搜返回 412；游客评论每视频只给 3 条热门回复（上限所致，非抓漏）；弹幕经 pagelist→list.so 可全量取（14.6 万条），但按委托方判断属低价值反应文本，**排除出分析**。
- **Patient.info**：Discourse 论坛，公开 JSON 分页：先列「心理健康」分类全部话题（34,320 个），再逐话题抓帖。是全语料治疗信号最密的源（长帖里每千篇 614 篇点名药物）。
- **Beyond Blue**（澳洲）：Khoros 社区 LiQL 接口，按版块查询分页；两波共 13 个版块。自杀念头版块按既定范围主动排除。
- **5ch**（日本）：.dat 原始文件直读（Shift-JIS 解码），先メンタルヘルス板，后扩人生相談、身体・健康、病院・医者、心理学四板。版块清单从官方 bbsmenu 破解（链接无引号 + 编码问题坑过一轮）。
- **LIHKG**（连登）：api_v2 免签名可用；帖子正文藏在 `item_data` 字段而非 `items`，找错字段全站归零——查对结构才出数。粤语文本要用粤语词典分类（返工/人工/供楼/冇钱），普通话词典测出 0.9% 痕迹率是假的，已作废重测。
- **2ch.hk**（俄）、**DC Inside**（韩）、**知恵袋/OKWave**（日）、**Naver Kin**（韩）、**Dcard**（台）、**Hilferuf**（德）、**MentalHealthForum**（英）：均为公开页面/API 逐帖抓取。DC Inside 第一版归零——正文结束标记的正则等一个页面上根本不存在的 div，6,000 次抓取静默全废；真标记是 comment_wrap。教训已固化：**任何爬虫启动后两分钟内必须核查落盘数**。
- **LiveJournal**：老牌 depression 社区（2001–2026）。列表分页翻不动，改按月归档页 /YYYY/MM/ 收割全部条目链接（约 2.9 万条），再逐条抓正文（正文标记 aentry-post__text，页面上另一个相似标记是广告横幅，坑过一次）。收割状态逐年落盘，重启不丢。
- **YouTube**：yt-dlp 按 12+ 种语言关键词搜视频再抓评论，两波 26,715 条；第三波时本机 IP 因当日抓取过密被官方标记，全部视频回「Sign in to confirm you're not a bot」，此路暂停（需登录 cookie，未经委托方指示不取用）。
- **Threads**：经用户连接的账号走官方接口。实测：此路径下临床词搜索返回空、词组可搜、每页文字帖仅约 2 条，全量 47 条。委托方本人于 App 内实测可正常搜到——故此现象只记为「本机接口路径的观察」，不定性为平台过滤（教训同知乎条：本机出口是美国数据中心 IP，多次被风控误伤，平台行为与本机可达性必须分开陈述）。
- **知乎**：内容本身游客公开（搜索引擎可索引全文）；本机被其风控拦截（API 回 40362 请求存在异常、浏览器被弹安全验证）。不是登录墙，是 IP 信誉问题，干净住宅 IP 可正常抓。
- **进不去的墙（如实登记，不硬闯）**：豆瓣/小红书/微博（登录或签名墙）、PTT/HealthBoards/NGA/Ekşi（本机 IP 被封）、Bluesky 搜索（需授权）、HKGolden（话题接口通、正文接口 404）、PsychForums（能抓但分页造假：每页都返回第一页内容，深抓 4,108 篇去重后仅剩 189 篇，已公开撤回原数字）。

## 四、账号注册审计（只查条款，未实际注册）

曾逐个平台核查注册门槛：只有 Reddit（邮箱+验证码）与 X（邮箱优先）属低门槛；知乎基础功能绑 +86 手机号、小红书非大陆号自 2025-12-08 起变 rednote 账号、微博/豆瓣/B站均需手机实名。且七个平台的用户条款全部禁止未授权自动抓取——**注册 ≠ 抓取许可**。最终全部数据均经游客/公开接口取得，没有实际注册任何账号。

## 五、清洗管线

统一流程（clean 系列脚本）：各源原始 jsonl → 字段归一（id/author/title/text/url/platform/lang）→ **双重去重**（先 id、后正文指纹）→ 长度与占位符过滤（[deleted]/[removed]/机器人账号剔除）→ 按平台输出 clean jsonl + 清洗报告（每源 in/kept/各类 drop 计数、总字数，全部可对账）。评论与帖子分开成流（评论是独立文本类型，单独统计）。版本量级：v1 15.3 万条 → v2 26.8 万 → v2.1 48.5 万 → v2.2 interim 279.9 万条 / 15.1 亿字（终版待三线收尾）。

**已知的假阳性来源，清洗时点名处理**：多个 HF 数据集经去重证明是同一份 7,731 行数据换名上架；OESD 中文集「孤独 76.6%」是词典假象（日常词误命中），跨语料禁止直接比百分比。

## 六、分类与计数方法（口径是这份研究的命门）

- **方法本质**：多标签词典匹配——一篇帖子可同时命中多个原因类别，份额相加可超过 100%。词典量的是「文本提到了什么」，不是病因鉴定；所有结论按此定位表述。
- **类别体系**：13 个归因类（工作/家庭/关系/孤独/疾病/童年创伤/丧亲/睡眠/产后/经济/遗传/无缘无故/困住）+ 5 个非因桶（症状感受/治疗药物/邻近诊断/虚无/想死未述因），非因桶单独报告、不混入归因。
- **分母规则（委托方定版）**：百分比只以「已分类帖」（至少命中一个归因类的帖）为分母；无分类与无原因帖一律剔除出分母，免得拖低比例。
- **经济问题三口径并行**（全研究最重要的设计）：①严口径——明说没钱/失业/欠债等窘迫词组；②宽口径——严 ∪「被工作/家庭/关系困住且走不掉」；③痕迹口径——任何金钱词汇出现（工资/房租/账单/贷款/保险/费用）。三口径差距本身就是结论：同一批 Reddit 长帖，严 4.7% → 痕迹 39.6%，后随样本放大至 11.1% / 59.5%（已分类基）。「钱占几成」没有单一答案，只有口径阶梯。
- **子串陷阱**：早期快扫曾报 34.1%，查明是 "rent" 命中 "parent" 的子串误报，当场撤回；此后经济词组全部用短语级匹配并抽样手检（随机抽 25 篇零命中长帖人工复核，确认无明显经济帖漏抓）。
- **多语种**：葡/西/法帖子用对应语言词典重扫（第一版曾用英文词典扫多语种帖、造成假「无分类」，已修复，无分类率从 39.7% 修至真实残余 13.9%）；日/韩/俄/德各有本语词典；粤语用粤语词典。
- **无分类的定性**：抽样证明「无分类」是仪器产物而非数据属性——里面是只讲症状的、问药的、邻近诊断的、支持者帖与多语种帖；加桶加词典后回收约六成五，余下约一成四为仪器地板，如实标注。

## 七、纠错纪律（这份研究的可信度来源）

1. 落盘优先：任何长跑任务两分钟内核查产出文件行数，日志说在跑不算数（DC Inside、PsychForums 两次大坑均由此揪出并公开更正）。
2. 数字撤回不留尾巴：子串误报 34.1%、PsychForums 4,108 篇、LIHKG 粤语假低值，均在验收报告中明文作废并给出修正值。
3. 平台定性双人复核式：知乎（登录墙→风控墙）、Threads（平台过滤→本机路径现象）两案，都是委托方以自身实测推翻初判后即时采纳修正——**用户实测 > 本机观察**，因为本机网络环境（美国数据中心出口 IP）本身就是已知的干扰源。
4. 估计与实数分离：凡投影数字（如拖网全跑完的量级）一律标注为估计；凡落盘数字给出来源文件与计数时间点。

## 八、限制与未竟

- 千万级语料的捷径（Pushshift 全站转储）已确认关闭（主存档被设为不可下载、镜像再三查无），本研究的量靠公开接口硬抓堆积，天花板即在此。
- 登录墙后的中文社群（豆瓣/小红书/微博）始终缺席，中文层靠 B站、连登、Dcard 与公开数据集补位，代表性有限，引用时须注明。
- 词典法测的是「自述归因」，测不到没说出口的结构性因素；经济学辩论的最终裁决因此是三层制（表面自述约一成 → 结构传导带最大 → 残余归身体与命运），而非任何单一百分比。
